# Styley Server repository instructions

These instructions apply to this independent backend repository, including when `server/` is opened as the workspace root.

Before inspecting, planning, editing, reviewing, or running project commands, read `.agents/skills/styley-server/SKILL.md` completely. Then read every focused skill it routes to for the current task. Supabase or Postgres work always requires `styley-server-data-supabase` and `styley-server-security`. Check for a more deeply nested `AGENTS.md` before changing files below it.

The Server owns business authority and public API contracts. Do not edit the sibling App or DesignSystem repositories unless the user explicitly includes them in the task.
